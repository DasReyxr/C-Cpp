# 12 TouchScreen
| Use Case                  | SPI Clock                                              |
| ------------------------- | ------------------------------------------------------ |
| Safe, always works        | **8–10 MHz**                                           |
| Typical STM32 projects    | **18–24 MHz**                                          |
| Fast and usually reliable | **30–42 MHz**                                          |
| Aggressive/optimized      | **48–65 MHz** (depends on module, wiring, PCB quality) |
