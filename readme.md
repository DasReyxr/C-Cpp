
# C-Cpp

This folder is a personal collection of C and C++ projects, microcontroller examples, notes, and course materials organized by topic and platform.

**Structure**:
- **Arduino/**: Arduino sketches and PlatformIO projects.
- **DasC/**: Small C exercises and examples (calculator, sorting, simple programs).
- **ESP/**: ESP8266/ESP32 example projects and demos.
- **Metodos/**: Numerical methods examples and related code (Gauss, Newton, integration, regression).
- **PIC-C/**: PIC microcontroller C projects and labs (Proteus schematics and CCS/PIC code).
- **STM32/**: STM32 projects, drivers, and example code.
- **PIC-C/**: CCS/PIC examples and student lab files.


**Boards Used**:
- STM32
  - STM32F103C8T6 (Blue Pill)
  - STM32F411CEU6 (Black Pill)
  - STM32F446ZET6 (Ray Pill)
- ESP
  - ESP8266 (NodeMCU, Wemos D1 Mini)
  - ESP32 (DevKitC, Wrover)
- PIC
  - PIC18F4550
- Arduino
  - Arduino Mega

**How to use**:
- Browse the subfolders for platform-specific examples and projects.
- For Arduino/PlatformIO projects, open the folder in VS Code with the PlatformIO extension.
- For PIC/Proteus examples, Proteus schematics and CCS code are usually stored together in the relevant `PIC-C/` subfolders.
- For STM32 and embedded projects, open the corresponding folder (e.g., `STM32/`) and follow any local README or build instructions present there.

**Tips & conventions**:
- Source files are generally placed next to their project assets (schematics, libraries, configs).
- Example names often include the target (e.g., PIC18F452, ESP8266, STM32F411) in filenames or folders.
